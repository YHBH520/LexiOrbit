# 词轨 LexiOrbit

面向大学英语四、六级备考的 Windows 词汇学习工具。全部学习功能免费，可自愿支持作者。

## 下载与安装

前往 [最新发行版](https://github.com/YHBH520/LexiOrbit/releases/latest)，下载 `LexiOrbit-Setup-1.2.35.exe`，运行安装向导。当前提供 Windows x64 版本；手机小程序尚未作为本仓库的正式发行内容。

安装包约 285 MiB，包含离线运行文件。程序尚未进行代码签名，Windows 可能提示未知发布者，请核对下载来源和 SHA-256。不要关闭系统安全防护；遇到安全拦截请先停止安装并反馈。

## 主要功能

- 四级、六级含基础、纯六级词库与不规则动词查询。
- 可旋转缩放的字母星球，以及词性、音标分类。
- 自动漫游、主动回忆、可调速快闪学习。
- 词义、双语例句、词形变化与固定搭配查询。
- 收藏、生词、复习计划、学习热力图和记忆测试。
- 词表导出打印、本地学习记录备份恢复。
- 多种视觉主题、本地图片与视频背景。

## 使用与数据

学习记录和个人资料主要保存在本机。卸载、重装或换电脑前，请使用软件内备份功能。发行包不包含作者的个人学习存档；同一台电脑已有的正式版记录可能在更新后继续显示。

发音可用性取决于系统音色及音频环境。例句和语法分析仍可能存在错误，欢迎反馈具体词条；不承诺考试成绩。自愿打赏不附带学习权益，也不会自动核验付款。留言在本机保存后仍需主动通过邮件入口发送。
